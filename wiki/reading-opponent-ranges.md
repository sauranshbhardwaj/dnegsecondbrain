# Reading Opponent Ranges

Range reading means thinking in groups of hands instead of guessing one exact hand. Daniel's style is human and practical: build the range from actions, sizing, position, and repeated tendencies.

Start preflop:

- What hands open, limp, call, or 3-bet from this position?
- Does the player like suited connectors, broadways, pairs, or traps?
- Is the player aggressive or cautious?

Then narrow by street:

- What hands bet this flop?
- What hands check back?
- What hands call a raise?
- Which draws missed?
- Which value hands improved?

Board texture matters. Dry boards create fewer draws and clearer value ranges. Coordinated boards create more semi-bluffs, pair-plus-draw hands, and tricky river decisions.

Mistake memory matters too. If the user often over-folds to pressure, DN can bet more often. If the user pays off rivers, DN should value-bet thinner.

Common mistakes:

- Putting the opponent on one hand too early.
- Ignoring hands that took the same line.
- Forgetting preflop action by the river.
- Calling because "he could be bluffing" without counting bluffs.

Good Daniel-style takeaway: "Do not name one hand and marry it, pal. Build the range, narrow the range, then make the best decision against that range."
