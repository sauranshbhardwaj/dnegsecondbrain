# DN Second Brain — Design Brief

## Aesthetic
Premium poker product. Dark theme only. Think high-stakes casino meets modern fintech.

## Color Palette
- Background: deep black (#0A0A0A) and dark charcoal (#111111)
- Felt: deep green (#0D2B1D) for the poker table surface
- Accent: gold (#C9A84C) for highlights, CTAs, and important UI elements
- Text primary: off-white (#F5F5F0)
- Text secondary: muted (#8A8A85)
- Danger/fold: muted red (#8B2635)
- Success/win: muted green (#2D6A4F)

## Typography
- Headings: sharp, confident — something like Playfair Display or a strong serif
- Body/UI: clean sans-serif — Inter or DM Sans
- DN coaching text: slightly larger, distinct treatment — this is the voice of the product

## Key Principles
- Nothing generic. No purple gradients. No rounded-everything cards.
- The table UI should feel like you are actually sitting at a felt table
- DN's coaching panel should feel like someone is talking to you, not showing you a report
- Minimal chrome — let the game and the coaching breathe
- Every animation is purposeful — only the typewriter effect on DN's response

## What to Avoid
- Bootstrap/MUI default aesthetics
- Generic hero sections with stock photos
- Rounded pill buttons everywhere
- Light mode
- Cluttered layouts
